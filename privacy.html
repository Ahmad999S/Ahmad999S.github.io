Privacy policy – Shaheen Assistant

Last updated: 23 October 2026

Who runs this app

Shaheen Assistant is a personal tool run by Dr Ahmad Yahya Shaheen. It is used only by him, with his own Google accounts. It has no other users.

What data it accesses

With the owner's permission, the app accesses the owner's own Google Drive files and Gmail messages through Google's APIs.

How the data is used

The data is used only to store, organise and read the owner's own files and email on his own private server. It is not sold, shared with third parties, used for advertising, or used to train general-purpose AI models.

Storage and security

Access tokens are stored on the owner's private server with restricted file permissions. Data stays in the owner's Google account and on that server.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
